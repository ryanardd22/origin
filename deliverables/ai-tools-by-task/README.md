# Video 5 — Pilih tool AI dari pekerjaannya

Video kartun 2D vertikal bernarasi Indonesia dengan subtitle tertanam. Empat peta tugas: draf desain Adobe Express, subtitle CapCut, materi bersumber Gemini Notebook, dan workflow AI n8n. Tool dan lingkup fitur diperiksa melalui rujukan resmi yang tercantum di sources.json.

Visual tugas merupakan ilustrasi orisinal; bukan screenshot antarmuka, hasil uji keempat aplikasi, atau bukti workflow yang telah terhubung. Contoh koreksi subtitle serta kutipan dokumen dibuat untuk menjelaskan cara memeriksa hasil. Tidak ada klaim akurasi sempurna, semua fitur gratis, atau tool terbaik universal. Prompt template Adobe dinyatakan bahasa Inggris sesuai sumber resmi.

Ekstrak semua isi ZIP lalu buka watch.html. MP4 bisa diputar langsung. Peta-tools-dan-prompt.txt menyediakan rujukan, contoh prompt, dan daftar pemeriksaan. Caption-posting.txt siap disalin; belum ada posting ke media sosial.

Nama Gemini Notebook mengikuti halaman bantuan resmi yang terbaca 5 November 2026 melalui pengalihan URL NotebookLM. Nama/tampilan dan paket dapat berubah; cek akun yang dipakai.
