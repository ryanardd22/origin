# Chatbot, workflow, dan agent

Video lengkap 58 detik dengan narasi Indonesia, subtitle, dan kartun 2D bergerak. Cerita mengikuti satu contoh: menyiapkan konten teknologi. Pembahasan dimulai dari percakapan, berlanjut ke workflow dan agent, lalu ditutup dengan rangkuman serta penjelasan bahwa satu aplikasi bisa menggabungkan pola-pola tersebut.

## Memutar video

Buka ai-explainer.mp4 langsung dengan pemutar video. Untuk paket ZIP, ekstrak seluruh isinya lalu buka watch.html. File preview.gif adalah cuplikan 9 detik tanpa suara; narasi lengkap ada di MP4.

Caption siap pakai: caption-posting.txt. Naskah: narasi.txt. Subtitle terpisah: subtitles.srt.

## Pemeriksaan

Format: 720 × 1280, 30 fps, 1.740 frame, H.264 yuv420p dan AAC stereo. Metadata serta dekode penuh lulus. Reviewer independen memeriksa cerita, sampel semua bagian, dan transisi; perbaikan label pada adegan bantuan sudah diterapkan.

Audio akhir terukur -16,2 LUFS dengan true peak -2 dBFS. Transkripsi otomatis lokal menangkap seluruh bagian utama narasi dan istilah penting. Penilaian pelafalan lewat pendengaran manusia belum dilakukan; laporan lengkap tersedia di qa-independent.md dan technical-report.json.

Paket dibagikan melalui branch preview origin sesuai metode akses sebelumnya. Tidak diposting ke media sosial. Source lokal: video-projects/cartoon-ai-explainer/. Paket tidak memuat API key.
