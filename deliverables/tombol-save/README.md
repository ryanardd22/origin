# Manusia Akhirnya Punya Tombol Save

Video storyboard beranimasi untuk peninjauan: 24 shot, 50 detik, vertikal 720×1280, 30 fps. Ilustrasi kartun 3D, gerak kamera, overlay, voiceover Indonesia, subtitle bertiming, dan musik instrumental asli.

Versi ini belum memiliki gerakan tubuh karakter dari model video. Generasi Google Gemini Omni ditolak karena Free Tier memiliki kuota video 0 request/hari. ComfyUI lokal juga belum memiliki GPU dan model video. Ilustrasi tidak boleh dianggap rekaman sejarah atau demonstrasi produk nyata.

Voiceover: ElevenLabs, voice bawaan Chris, eleven_multilingual_v2. Audio asli dipercepat 1.33× untuk tempo; subtitle mengikuti timestamp provider yang disesuaikan. Font disertai lisensinya pada source proyek.

Tidak ada API key di paket. Paket dibagikan melalui branch `deliverables/tombol-save-video` di GitHub origin sesuai permintaan akses unduhan. Tidak diposting ke media sosial. Bahan produksi dan source ada lokal di video-projects/tombol-save/.

## Memutar secara offline

Ekstrak seluruh ZIP ke satu folder, lalu buka watch.html atau langsung buka tombol-save-preview.mp4 dengan pemutar video. Jangan membuka watch.html dari dalam ZIP sebelum mengekstraknya.

## Pemeriksaan

Decode penuh lulus: 1500 frame, 50 detik, H.264 yuv420p dan AAC stereo. Reviewer independen memeriksa sampel seluruh shot dan batas transisi; tidak ditemukan blocker visual. Audio terukur -16.1 LUFS dengan true peak -2.2 dBFS, tetapi belum dinilai lewat pendengaran. Transkripsi otomatis Google gagal HTTP503 dan bukan bukti verifikasi audio.
