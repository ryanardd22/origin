# Hidden Gem — video simulasi

- [Unduh MP4](./hidden-gem-mobile.mp4?raw=true)
- [Unduh ZIP](./hidden-gem-mobile.zip?raw=true) — ekstrak ZIP lalu buka MP4.

Video 35 detik, vertikal 720×1280, H.264 Baseline/yuv420p, AAC stereo. Musik instrumental, tanpa voiceover. Format sudah diperiksa dengan ffprobe dan ZIP telah diuji integritasnya. Pemutaran pada seluruh browser/perangkat belum diverifikasi.

Angka Rp2.970.000 adalah simulasi omzet kotor (30 pembeli × Rp99.000), bukan hasil nyata atau jaminan pendapatan. Contoh kit digital dalam video adalah ilustrasi penawaran. Visual mengikuti warna thumbnail melalui motion graphics baru, tidak menggunakan foto wajah/saldo dari thumbnail.

Diupload ke repositori publik origin atas instruksi pemilik; tidak dipublikasikan ke media sosial. Branch ini hanya memuat file pengiriman video, tidak membawa perubahan website atau wrapper yang masih lokal.
