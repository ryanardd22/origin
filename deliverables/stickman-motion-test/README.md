# Tes gerak stickman — 5 detik

Animasi 2D yang dibuat langsung lewat kode SVG/Remotion. Kaki, lutut, bahu, siku, tangan, kepala, tablet, pena dan garis tulisan diperbarui per frame. Kamera dan meja tetap. Tidak memakai foto, video generatif, API berbayar atau GPU.

Urutan: berjalan 0–1.5 detik, meraih 1.5–2.17, mengangkat tablet 2.17–2.83, lalu menulis sampai akhir. Format MP4 H.264 yuv420p, 720×1280, 30fps, AAC stereo. GIF adalah preview tanpa suara pada 12fps; MP4 memiliki efek bunyi sintetis asli tanpa narasi.

Ekstrak ZIP dan buka watch.html atau MP4. Source proyek tersimpan lokal di video-projects/stickman-motion-test/. Pemeriksaan metadata dan decode penuh lulus. Sampel visual diperiksa; audio belum dinilai melalui pendengaran. Ini tes gerakan singkat, bukan film penuh 50 detik.
